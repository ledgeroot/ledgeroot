# 文档索引

> Ledgeroot 是 agent x402 支付的证据引擎：授权（mandate）→ 执行前 fail-closed 校验 → 六段收据 → 哈希链 → 链上锚定 → 离线三态验证。本文档集记录它的**架构现状与行动计划**。
